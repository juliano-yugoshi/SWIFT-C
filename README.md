# SWIFT-C

**A Unified Framework for Short Video Clustering with Natural-Language Weak Labels**

SWIFT-C is a Python package for clustering text-described items using
natural-language weak labels suggested independently by multiple language
models. It provides different ways to incorporate weak-label semantics
into the clustering process and makes it possible to compare those
strategies using common inputs and evaluation protocols.

Short videos are the application studied in the associated paper. The
package also accepts other collections in which each item has a text
description and one or more textual suggestions.

## Main features

1. Semantic representation fusion of descriptions and weak labels with
   individually configurable integration weights.
2. Graph-based clustering, including spectral clustering, multiview
   evidence accumulation, and uniform or adaptive weak-label refinement.
3. Deep Embedded Clustering (DEC) on original or fused representations,
   plus K-means, spherical K-means, and HDBSCAN baselines.
4. Discrete must-link baselines based on normalized textual agreement.
   The discrete baseline is separate from the semantic methods.
5. Synthetic scenario generation and evaluation for conditions such as
   complementary labels, paraphrases, missing evidence, misleading
   suggestions, class imbalance, and non-spherical clusters.
6. Method selection using completed synthetic results and post-hoc
   cluster-based recommendation evaluation.
7. Cached embeddings, resumable experiments, per-run predictions,
   structured CSV results, and reproducible configuration files.

## Installation

Python 3.10 or newer is required. Install the basic package with

```bash
pip install -e .
```

Install the additional dependencies required for Qwen embeddings, DEC,
publication plots, and tests with

```bash
pip install -e ".[all]"
```

Check the available commands with

```bash
swiftc --help
swiftc methods
swiftc realworld --help
swiftc synthetic --help
```

Interactive examples are also available in `examples/notebooks/`.

The package installs one command named `swiftc`. No separate installation
of the four original research packages is necessary.

## Dataset and input mapping

The included `data/MSRVTT_dados_multillm.zip` contains the CSV dataset used
in the article. Each of its 10,000 rows corresponds to one short video.
The records include a description generated by a multimodal model,
thematic suggestions from Gemini, Claude, and Llama, and a reference
category for evaluation. Video files and pretrained model weights are not
part of the repository.

The accompanying `configs/msrvtt.json` specifies which columns contain
item identifiers, descriptions, weak-label suggestions, and evaluation
categories. Suggestions generated from a predefined category inventory
are not included among the clustering inputs.

For another dataset, create a JSON mapping with `swiftc configure` or
edit `configs/example_mapping.json`. The clustering library is not tied
to a particular dataset, set of LLMs, or number of clusters.

## Real-world clustering

Use the included dataset to run a small experiment.

```bash
swiftc realworld \
  --input data/MSRVTT_dados_multillm.zip \
  --mapping configs/msrvtt.json \
  --encoder Qwen/Qwen3-Embedding-0.6B \
  --device cuda \
  --profile quick \
  --methods input,labels_only,fusion,spectral_fusion \
  --clusters 20 \
  --seeds 42 \
  --sources all \
  --output results/real_quick
```

For the full collection, use `--profile full`. With a selected method
suite, adjust `--methods`, `--clusters`, `--seeds`, and `--sources` as
needed. The `--suite` option provides core, quick, and paper presets.
Models are not fine-tuned during standard embedding extraction.

Intermediate embeddings are stored in `embedding_cache/` in the results
directory and are reused on subsequent runs when the configuration and
text inputs match. Completed predictions are also cached and the run
can resume after interruption.

For a dataset with different column names, run

```bash
swiftc inspect --input my_dataset.csv
swiftc configure --input my_dataset.csv --output configs/my_dataset.json
swiftc realworld \
  --input my_dataset.csv \
  --mapping configs/my_dataset.json \
  --profile full \
  --methods fusion,spectral_fusion,eac_adaptive \
  --clusters 20 \
  --seeds 42,123,2025 \
  --sources all \
  --output results/my_dataset
```

You may set `target_column` to null in the mapping when reference
categories are unavailable. Reference labels are not used to construct
the clusters.

## Synthetic experiments

Controlled synthetic scenarios make it possible to inspect when noisy or
complementary weak labels improve clustering and when they lead to
negative transfer.

```bash
swiftc synthetic \
  --profile quick \
  --suite quick \
  --output results/synthetic_quick
```

To evaluate a specific subset of scenarios, use `--scenarios` with a
comma-separated list of scenario names. The general package also includes
internal sanity checks, which are not part of the publication results.

## Discrete weak-label baselines

The discrete evaluation operates on textual suggestion identity rather
than embedding similarity. To execute the fixed-K must-link comparison,
reuse an embedding cache from a completed real-world run.

```bash
swiftc discrete \
  --input data/MSRVTT_dados_multillm.zip \
  --embeddings results/real_full/embedding_cache \
  --k 20 \
  --output results/discrete
```

The command also reports direct-label voting as diagnostic baselines.
These have an unconstrained number of clusters. The paper uses only
discrete must-link as a matched fixed-K baseline.

## Cluster-based video discovery

Use saved cluster assignments to retrieve similar videos from within the
query video's assigned cluster. The retrieval code does not fit a new
clustering model.

```bash
swiftc retrieval \
  --results results/real_full \
  --discrete results/discrete \
  --input data/MSRVTT_dados_multillm.zip \
  --embeddings results/real_full/embedding_cache \
  --topk 1,3,5,10 \
  --source-sets all \
  --k 20 \
  --output results/video_discovery
```

With `--embeddings`, candidates are ranked by cosine similarity between
original description embeddings. The ranking stage evaluates Precision@k,
Recall@k, and mAP@k using reference categories as a proxy for relevance.
It does not evaluate unrestricted global nearest-neighbor search.

## Selecting methods for real data

A separate command summarizes completed synthetic results, checks
coverage, and generates scripts for a manageable real-world comparison.

```bash
swiftc select \
  --results results/synthetic_quick \
  --output results/selection \
  --allow-partial \
  --top-n 2 \
  --real-input data/MSRVTT_dados_multillm.zip \
  --mapping configs/msrvtt.json
```

The output contains a method ranking, pairwise comparisons, and runnable
scripts that use the same `swiftc` executable. Selection should be based
on synthetic experiments, not real-world reference labels.

## Reproducing the paper

The package is general-purpose. The exact article protocol is a separate
workflow in `paper/` and does not change the default library behavior.

```bash
python paper/reproduce.py --stage all --dry-run
```

Reproduction can be executed in stages to preserve intermediate results.
Read `paper/README.md` for the full instructions and hardware notes.
    The repository module organization is documented in `ARCHITECTURE.md`.
The `paper/protocol.json` file records all fixed experimental choices.
    The execution script also saves a provenance manifest with dataset hashes,
    dependency versions, and completed stages.

## Output formats

Clustering writes `runs.csv`, per-run predictions, method reports, and
intermediate graph and embedding caches. The discrete baselines write
`metrics.csv` and `predictions.csv`. Retrieval writes `ranking_summary.csv`
and `ranking_per_run.csv` when Top-K scoring is enabled. All outputs are
available for subsequent analysis without rerunning the models.
